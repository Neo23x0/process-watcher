# Kernel table for tests/vm/run.sh.
#
# One line per (kernel-id, arch). Columns, separated by blanks:
#
#   kernel-id  arch  package-version  kernel-URL  kernel-SHA256  [config-URL  config-SHA256]
#
# kernel-URL points to the linux-image .deb. run.sh downloads it over HTTPS,
# refuses it unless the SHA-256 matches, extracts only /boot/vmlinuz-* from it
# and caches the result under tests/vm/cache/kernels/<arch>/<kernel-id>/. No
# kernel modules are used: the console, initramfs, BPF and BTF code is built
# into all of these kernels.
#
# config-URL (optional) is a small package that carries the build configuration
# of exactly that kernel (Ubuntu: linux-buildinfo). The kernels do not export
# /proc/config.gz, so the guest prints the BPF/BTF/HZ facts from this copy.
# Debian ships /boot/config-* inside the linux-image .deb itself, so Debian
# rows need no extra columns.
#
# All checksums come from the Packages indexes of the archives, after the
# InRelease signature had been verified with the distribution keyring
# (tests/vm/container/resolve-kernel.sh does exactly that). To move a kernel id
# to a newer package, run that script, paste the new URLs and checksums here
# (a changed checksum invalidates the cache entry by itself).
#
# kernel-id    arch   version           kernel-URL ... kernel-SHA256 ... config-URL ... config-SHA256
